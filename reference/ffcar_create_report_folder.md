# Create Folders and Subfolders for Report

Function to create a folder and subfolders for a standard
`ffcar`-compatible report.

## Usage

``` r
ffcar_create_report_folder(chr_folder_name)
```

## Arguments

- chr_folder_name:

  A character string, the folder name. For compatibility with `ffcar`
  functions, folder names must start with a letter and can only contain
  letters, numbers, underscores, or periods.

## Value

Creates a folder with relevant subfolders.
