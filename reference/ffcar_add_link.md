# Create RMarkdown Code for a Link

Function that creates the code to add a line with a link (e.g., a link
to the table of contents) to a RMarkdown file.

## Usage

``` r
ffcar_add_link(chr_content = "", chr_link = "")
```

## Arguments

- chr_content:

  A character string, the text content of the hyperlink.

- chr_link:

  The internal link to use.

## Value

A character string.
